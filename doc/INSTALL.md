# Инструкция по установке и настройке GR2-0 Community Bot

## Требования

-   Python 3.8+
-   pip (менеджер пакетов Python)
-   Telegram Bot Token
-   Доступ к группам Telegram

## Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd gr2_bot
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

## Настройка

### 1. Создание бота в Telegram

1. Напишите [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните полученный токен

### 2. Настройка конфигурации

#### Основная конфигурация бота

Отредактируйте файл `data/private/config/bot_config.json`:

```json
{
    "bot": {
        "token": "YOUR_BOT_TOKEN_HERE",
        "username": "your_bot_username"
    },
    "groups": {
        "community": "YOUR_COMMUNITY_GROUP_ID",
        "admin": "YOUR_ADMIN_GROUP_ID"
    },
    "settings": {
        "qr_code_interval": 30,
        "daily_check_time": "21:00",
        "feedback_collection_hours": 24
    }
}
```

#### Настройка системы поинтов

Отредактируйте файл `data/private/config/points_config.json`:

```json
{
    "actions": {
        "registration": 1,
        "meetup_attendance": 7,
        "feedback_response": 1
    },
    "feedback": {
        "min_length_for_points": 128,
        "questions": [
            "Оценка доклада 1",
            "Оценка доклада 2",
            "Оценка доклада 3",
            "Общий фидбек о митапе"
        ]
    }
}
```

### 3. Получение ID групп

#### ID группы коммьюнити

1. Добавьте бота в группу коммьюнити
2. Отправьте в группу команду `/start`
3. Перейдите по ссылке: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
4. Найдите в ответе `"chat":{"id": -XXXXXXXXX}` - это ID группы

#### ID админской группы

1. Добавьте бота в админскую группу
2. Отправьте в группу команду `/start`
3. Получите ID аналогично предыдущему шагу

### 4. Настройка прав бота

#### В группе коммьюнити

-   Добавить бота как участника
-   Дать права на чтение сообщений
-   Дать права на отправку сообщений

#### В админской группе

-   Добавить бота как участника
-   Дать права на чтение сообщений
-   Дать права на отправку сообщений

## Запуск

### 1. Активация виртуального окружения

```bash
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 2. Запуск бота

```bash
python main.py
```

### 3. Проверка работы

1. Отправьте боту команду `/start`
2. Проверьте, что бот отвечает
3. Проверьте логи в файле `bot.log`

## Основные команды бота

### Пользовательские команды

-   `/start` - регистрация/приветствие
-   `/help` - справка по командам
-   `/profile` - профиль пользователя
-   `/points` - баланс поинтов

### Админские команды

-   `/meetup` - управление митапами
-   `/admin` - управление админами
-   `/stats` - статистика коммьюнити
-   `/users` - управление пользователями
-   `/qr_start` - запуск QR-регистрации на митап
-   `/qr_stop` - остановка QR-регистрации
-   `/qr_status` - статус QR-регистраций
-   `/debug_meetups` - отладочная информация о митапах

## Устранение неполадок

### Бот не отвечает

1. Проверьте правильность токена
2. Убедитесь, что бот добавлен в группы
3. Проверьте права бота в группах
4. Посмотрите логи в `bot.log`

### Ошибки с группами

1. Проверьте правильность ID групп
2. Убедитесь, что бот имеет доступ к группам
3. Проверьте права бота в группах

### Проблемы с QR-кодами

1. Убедитесь, что установлен Pillow
2. Проверьте права на запись в папку `data/private/qr_codes`

## Разработка

### Добавление новых команд

1. Создайте обработчик в `src/bot.py`
2. Добавьте команду в `setup_handlers()`
3. Добавьте сообщения в `data/public/messages/bot_messages.json`

### Изменение бизнес-логики

1. Отредактируйте соответствующие модули в `src/models/`
2. Обновите конфигурацию в `data/private/config/`
3. Протестируйте изменения

### Добавление новых функций

1. Создайте новые модули в `src/`
2. Обновите зависимости в `requirements.txt`
3. Добавьте тесты в `tests/`

## Поддержка

При возникновении проблем:

1. Проверьте логи в `bot.log`
2. Убедитесь в правильности конфигурации
3. Проверьте права доступа к файлам и папкам
4. Обратитесь к документации Telegram Bot API

## Лицензия

Проект разработан для внутреннего использования GR2-0 коммьюнити.
