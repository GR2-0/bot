# QR-регистрация на митапы

## Обзор

Система QR-регистрации позволяет администраторам запускать автоматическую генерацию QR-кодов для регистрации участников на активные митапы. Каждый QR-код действителен в течение 30 секунд и может быть использован только одним пользователем.

## Основные возможности

-   🚀 **Автоматическая генерация QR-кодов** каждые qr_code_interval секунд
-   👑 **Административное управление** - только админы могут запускать/останавливать
-   🔒 **Безопасность** - каждый код уникален и одноразовый
-   ⏰ **Автоматическое завершение** при окончании митапа
-   💎 **Начисление поинтов** за посещение митапа
-   📊 **Статистика** регистраций в реальном времени

## Команды администратора

### `/qr_start` - Запуск QR-регистрации

Запускает процесс генерации QR-кодов для выбранного митапа.

**Требования:**

-   Пользователь должен быть администратором
-   Митап должен быть в статусе "active"
-   Для митапа не должна быть уже запущена QR-регистрация

**Процесс:**

1. Админ выбирает активный митап из списка
2. Бот запускает автоматическую генерацию QR-кодов
3. Каждые 30 секунд админ получает новый QR-код
4. QR-код содержит хеш для регистрации и глубокую ссылку

### `/qr_stop` - Остановка QR-регистрации

Останавливает процесс генерации QR-кодов для выбранного митапа.

**Требования:**

-   Пользователь должен быть администратором
-   Для митапа должна быть активна QR-регистрация

### `/qr_status` - Статус QR-регистраций

Показывает текущий статус всех активных QR-регистраций.

**Информация:**

-   Название митапа
-   Время запуска регистрации
-   Количество зарегистрированных участников
-   Время последнего сгенерированного QR-кода

## Процесс регистрации пользователя

### 1. Получение QR-кода

Пользователь получает QR-код от администратора (отсканировав или получив хеш).

### 2. Регистрация по QR-коду

Пользователь может зарегистрироваться двумя способами:

#### Способ 1: Отправка хеша

Пользователь отправляет 16-символьный хеш боту в виде обычного сообщения.

#### Способ 2: Глубокая ссылка (Deep Link)

Пользователь переходит по ссылке из QR-кода, которая автоматически открывает чат с ботом и обрабатывает регистрацию.

### 3. Валидация и регистрация

Бот проверяет:

-   Существование пользователя в системе
-   Активность QR-регистрации для митапа
-   Валидность хеша
-   Отсутствие дублирующей регистрации

### 4. Начисление поинтов

При успешной регистрации пользователь получает поинты согласно настройкам в `points_config.json` (по умолчанию 7 поинтов за `meetup_attendance`).

## Безопасность

### Защита от повторного использования

-   Каждый QR-код может быть использован только один раз
-   Пользователь может зарегистрироваться на митап только один раз
-   QR-коды автоматически истекают через 10 секунд

### Валидация

-   Проверка существования пользователя в системе
-   Проверка активности митапа
-   Проверка уникальности регистрации
-   Проверка срока действия QR-кода

## Автоматизация

### Генерация QR-кодов

-   Автоматическая генерация каждые 30 секунд
-   Отправка админу с информацией о митапе
-   Обновление статистики в реальном времени
-   Автоматическая очистка старых QR-файлов и сообщений

### Очистка

-   Автоматическая остановка при завершении митапа
-   Периодическая очистка истекших регистраций (каждые 5 минут)
-   Отмена задач генерации при остановке
-   Автоматическое удаление QR-файлов после использования
-   Очистка старых сообщений с QR-кодами

## Настройки

### Интервал генерации

Настраивается в `bot_config.json`:

```json
{
    "settings": {
        "qr_code_interval": 30
    }
}
```

### Поинты за посещение

Настраивается в `points_config.json`:

```json
{
    "actions": {
        "meetup_attendance": 7
    }
}
```

## Обработка ошибок

### Типичные ошибки

-   **QR-код недействителен** - код истёк или не существует
-   **Пользователь уже зарегистрирован** - дублирующая регистрация
-   **Митап не активен** - регистрация завершена
-   **Пользователь не найден** - необходимо зарегистрироваться в боте

### Логирование

-   Все операции регистрации логируются
-   Ошибки генерации QR-кодов записываются в лог
-   Статистика регистраций сохраняется
