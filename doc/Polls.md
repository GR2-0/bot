# Система опросов (Polls)

## Обзор

Система опросов позволяет администраторам создавать и проводить опросы среди пользователей бота через приватные сообщения. Опросы поддерживают два типа вопросов: с вариантами ответов (`single_choice`) и с текстовыми ответами (`text`).

## Архитектура

Система реализована в виде единого модуля `src/polls.py`, который содержит:

-   `PollsManager` - класс для управления опросами и данными
-   `BotPollsHandlers` - класс для обработки пользовательского интерфейса в боте
-   `polls_manager` - глобальный экземпляр для обратной совместимости

### Структура директорий

```
data/private/polls/
├── config/          # Конфигурации опросов
│   ├── poll_001.json
│   ├── poll_002.json
│   └── ...
└── results/         # Результаты опросов
    ├── poll_001_2025-01-15.json
    ├── poll_002_2025-01-16.json
    └── ...
```

### Команды бота

-   `/polls` - Управление опросами (только для админов)
-   Показывает список доступных опросов
-   Позволяет запускать и останавливать опросы
-   Отображает активные опросы

## Конфигурация опроса

### Структура файла конфигурации

Каждый файл конфигурации опроса должен находиться в `data/private/polls/config/` и иметь формат `poll_XXX.json`, где XXX - уникальный ID опроса.

```json
{
    "id": "poll_001",
    "title": "Оценка митапа GR2.0",
    "description": "Помогите нам улучшить качество митапов",
    "target_audience": {
        "type": "meetup_attendees",
        "meetup_id": "53378e72-0772-468c-8d5a-6df033e23fbf"
    },
    "questions": [
        {
            "id": "q1",
            "type": "single_choice",
            "text": "Как вы оцениваете организацию митапа?",
            "options": ["Отлично", "Хорошо", "Удовлетворительно", "Плохо"],
            "required": true
        },
        {
            "id": "q2",
            "type": "text",
            "text": "Что можно улучшить в следующих митапах?",
            "max_length": 500,
            "required": false
        },
        {
            "id": "q3",
            "type": "single_choice",
            "text": "Будете ли вы участвовать в следующих митапах?",
            "options": [
                "Да, обязательно",
                "Скорее всего да",
                "Не знаю",
                "Скорее всего нет",
                "Нет"
            ],
            "required": true
        }
    ],
    "settings": {
        "anonymous": true,
        "allow_multiple_responses": false
    },
    "created_at": "2025-01-15T10:00:00+03:00",
    "created_by": "342122747"
}
```

### Описание полей конфигурации

#### Основные поля

-   `id` (string, обязательное) - Уникальный идентификатор опроса
-   `title` (string, обязательное) - Заголовок опроса
-   `description` (string, опциональное) - Описание опроса
-   `target_audience` (object, обязательное) - Целевая аудитория
-   `questions` (array, обязательное) - Список вопросов
-   `settings` (object, обязательное) - Настройки опроса
-   `created_at` (string, обязательное) - Дата создания (ISO 8601)
-   `created_by` (string, обязательное) - ID администратора-создателя

#### Поле target_audience

Определяет, кому будет отправлен опрос:

```json
{
    "type": "all_users", // Всем пользователям
    "meetup_id": null
}
```

или

```json
{
    "type": "meetup_attendees", // Только участникам конкретного митапа
    "meetup_id": "53378e72-0772-468c-8d5a-6df033e23fbf"
}
```

#### Типы вопросов

**1. single_choice** - Один вариант ответа

```json
{
    "id": "q1",
    "type": "single_choice",
    "text": "Ваш любимый язык программирования?",
    "options": ["Python", "JavaScript", "Java", "C++"],
    "required": true
}
```

**2. text** - Текстовый ответ

```json
{
    "id": "q2",
    "type": "text",
    "text": "Ваши предложения по улучшению:",
    "max_length": 1000,
    "required": false
}
```

#### Настройки опроса

-   `anonymous` (boolean) - Анонимный опрос (не сохранять user_id)
-   `allow_multiple_responses` (boolean) - Разрешить повторные ответы

**Важно**: Автоматическое завершение опросов отключено. Опросы запускаются и останавливаются только вручную администраторами.

## Логика работы

### 1. Создание опроса

1. Администратор создает JSON-файл конфигурации в `data/private/polls/config/`
2. Файл должен соответствовать схеме, описанной выше
3. ID опроса должен быть уникальным

### 2. Запуск опроса

1. Администратор отправляет команду `/polls`
2. Бот показывает список доступных конфигураций опросов
3. Администратор выбирает опрос для запуска
4. Бот определяет целевую аудиторию:
    - Если `target_audience.type = "all_users"` - отправляет всем пользователям из `users.json`
    - Если `target_audience.type = "meetup_attendees"` - отправляет только участникам указанного митапа из поля `attendees`
5. Бот отправляет опрос в приватные сообщения каждому пользователю
6. Создается файл результатов в `data/private/polls/results/`

### 3. Прохождение опроса пользователем

1. Пользователь получает сообщение с опросом и кнопкой "Начать опрос"
2. После нажатия кнопки начинается последовательное прохождение вопросов
3. Для вопросов `single_choice` отображаются inline-кнопки с вариантами ответов
4. Для вопросов `text` пользователь вводит текстовый ответ
5. Бот автоматически переходит к следующему вопросу после ответа
6. После завершения всех вопросов результаты автоматически сохраняются

### 4. Завершение опроса

1. Администратор останавливает опрос вручную через команду `/polls`
2. Результаты финализируются и сохраняются

## Валидация конфигурации

### Обязательные поля

-   `id` - не пустой, уникальный
-   `title` - не пустой
-   `target_audience` - валидный объект с полем `type`
-   `questions` - не пустой массив
-   `created_at` - валидная дата ISO 8601
-   `created_by` - существующий ID администратора

### Валидация вопросов

-   `id` - уникальный в рамках опроса
-   `type` - один из: `single_choice`, `text`
-   `text` - не пустой
-   `required` - boolean
-   Для вопросов `single_choice`: `options` - не пустой массив
-   Для вопросов `text`: `max_length` - положительное число (опционально)

### Валидация целевой аудитории

-   `type` - один из: `all_users`, `meetup_attendees`
-   Если `type = "meetup_attendees"`, то `meetup_id` должен существовать в `meetups.json`

## Обработка ошибок

### Ошибки конфигурации

-   Некорректный JSON
-   Отсутствующие обязательные поля
-   Невалидные значения полей
-   Дублирующиеся ID вопросов
-   Несуществующий meetup_id

### Ошибки во время опроса

-   Пользователь не найден в целевой аудитории
-   Опрос истек
-   Невалидный ответ пользователя
-   Технические ошибки отправки сообщений

## Безопасность

-   Только администраторы могут создавать и запускать опросы
-   Валидация всех входных данных
-   Защита от SQL-инъекций (использование JSON)
-   Ограничение длины текстовых ответов
-   Проверка прав доступа к результатам

## Производительность

-   Асинхронная отправка сообщений через Telegram Bot API
-   Единый файл результатов для каждого опроса
-   Валидация ответов без сохранения промежуточных состояний
-   Автоматическое создание директорий для результатов
-   Оптимизированная обработка callback'ов и текстовых ответов

## Техническая реализация

### Модуль polls.py

Система реализована в едином модуле `src/polls.py` со следующей структурой:

#### PollsManager

-   `list_poll_configs()` - получение списка доступных опросов
-   `load_poll_config(poll_id)` - загрузка конфигурации опроса
-   `is_poll_active(poll_id)` - проверка активности опроса
-   `start_poll(poll_id, started_by)` - запуск опроса
-   `record_response(poll_id, user_id, answers)` - запись ответа пользователя
-   `finalize_poll(poll_id)` - завершение опроса
-   `validate_complete_answers(config, answers)` - валидация ответов

#### BotPollsHandlers

-   `polls_command(update, context)` - обработка команды `/polls`
-   `handle_poll_callback(update, context)` - обработка callback'ов
-   `handle_poll_text_response(update, context)` - обработка текстовых ответов
-   `_start_poll_for_user()` - начало опроса для пользователя
-   `_show_poll_question()` - отображение вопроса
-   `_save_user_response()` - сохранение ответов пользователя

#### Интеграция с ботом

Модуль интегрируется с основным ботом через импорт в `src/bot.py`:

```python
from polls import BotPollsHandlers
```
